Before you book

Does the delivered file work offline?

Yes. The delivered HTML includes the model and selected photos. Download it and open it in a compatible desktop browser such as Chrome. The website demos are separate, web-optimized examples.

Are future site updates included?

No. The package covers one capture and delivery. Future visits and updated models are priced separately. Recurring progress plans can be scoped around project milestones.

Can I use this for measurements or earthwork quantities?

This package is for visual documentation and communication. It is not a licensed land survey, verified dimensional model, quantity report, engineering opinion or BIM deliverable.

Is this a live digital twin?

It is a visual digital twin of conditions on one capture date. It does not contain a live sensor feed or automatically update as construction changes.

Can my team and clients keep using it?

Yes. The delivered viewer can be viewed and shared without a viewer subscription or per-seat fees. Unlimited use does not include additional site visits or new model production.
