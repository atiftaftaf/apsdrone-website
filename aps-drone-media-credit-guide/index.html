APS Drone Media Credit and Usage Guide

Use these copy-ready credits when publishing aerial photographs or video created by APS Drone. Keep the wording factual, link the business name to the canonical website and follow the usage terms in the applicable project agreement.

Quick answer

The preferred website credit is Aerial media by APS Drone. On Instagram, use “Aerial media by @apsdronetx.” A credit must never imply that APS Drone endorses a property, contractor, claim or conclusion.

Copy-and-paste HTML

Use this code in a website credit, project page, article or vendor acknowledgment when the site allows linked credits:

Standard linked credit

<p>Aerial media by <a href="https://apsdrone.com/">APS Drone</a>.</p>

Use a normal editorial link. Do not add keyword-stuffed anchor text, hidden links, sitewide footer links or a reciprocal-link requirement.

Social attribution

  • Instagram: Aerial media by @apsdronetx
  • TikTok: Aerial media by @apsdronetx
  • Facebook: tag the official APS Drone business page when available
  • Keep the credit close to the media or in the caption

Accessible publishing

  • Write alt text that describes the visible property or scene
  • Do not stuff alt text with service keywords
  • Add captions when the location or project context helps readers
  • Do not expose private names, addresses or security-sensitive details

Logo files

Use the APS Drone logo only to identify the media provider. Preserve its proportions, contrast and clear space; do not recolor it or imply a partnership beyond the real project relationship.

Usage and accuracy rules

Follow the agreement

The delivery agreement controls the licensed use, media scope and any credit requirement. This page is practical guidance, not a replacement license.

Describe only what is visible

Do not present roof, thermal or mapping imagery as an engineering diagnosis, code determination or licensed survey.

Protect private information

Publish customer names, exact addresses and project details only when the customer has authorized them.

Do not imply endorsement

A media credit identifies the creator. It does not endorse a listing, contractor, product, condition or professional conclusion.

Media credit questions

Is a credit always required?

The applicable project agreement controls usage and credit requirements. When credit is appropriate, use the factual wording on this page.

Which APS Drone URL should I link?

Use https://apsdrone.com/ for the business credit. A relevant service, project or planning-resource URL can be used when it directly supports the surrounding content.

May I use the logo?

Use it only to identify APS Drone as the media provider and preserve its appearance. Do not imply sponsorship or a broader partnership that does not exist.

Can the credit name the project address?

Only when the customer has authorized that disclosure and it is appropriate for the publication. A simple business credit does not require an address.
